MAGENAIS / Models

A catalog of models you can run without the platform they came from.

Each model below is its own independent, open-source repository — clone it, read it, run it on its own. The MAGENAIS platform is one consumer of this catalog, not the only way in.

No API key, no account, and no cloud service is required to run any of them.

Models

A model is listed here as published once it has a tagged, tested release in its own repository. A model whose source is already public but not yet tagged/released appears as in development, with a link to its repository. Anything with no repository yet appears as planned, so you can see what's coming.

For developers

The catalog and its schemas are plain files — read them directly, or point your own tooling at them.

  • catalog/models.json Machine-readable list of published models
  • model-manifest.schema.json What a model publishes about itself
  • model-response.schema.json What a model returns when run
  • Source on GitHub Contributions welcome — see CONTRIBUTING.md

Catalog metadata and schemas are Apache-2.0 licensed. Each model repository carries its own license. MAGENAIS Core, the platform that consumes this catalog, is separate and proprietary — this catalog does not depend on it, and neither does any model listed here.
