MAGENAIS Models3 published models · 0 API key required

A catalog of models you can run without the platform they came from.

Each model below is its own independent, open-source repository — clone it, read it, run it on its own. The MAGENAIS platform is one consumer of this catalog, not the only way in. No API key, no account, and no cloud service is required to run any of them.
